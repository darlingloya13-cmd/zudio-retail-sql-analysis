# 🛍️ Zudio Retail Expansion & Demographic Location Intelligence

## 📌 Project Overview
This project performs exploratory data analysis (EDA) and location intelligence on Zudio retail stores across India using **MySQL**. By analyzing demographic metrics, per capita income, mall density, and priority expansion indices, this project identifies high-potential markets and uncovers strategic insights for retail real estate site selection.

## 🛠️ Tech Stack
- **Database**: MySQL / MySQL Workbench
- **Language**: SQL (DDL, Aggregations, CASE Statements)
- **Version Control**: Git & GitHub

## 📂 Repository Files
- **`schema.sql`**: Database setup and table creation structure (with data cleaning preprocessing notes).
- **`analysis_queries.sql`**: Core SQL queries for regional footprints, economic correlations, and underserved market gaps.
